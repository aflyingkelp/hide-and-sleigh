# Hide & Sleigh

[Play on GitHub Pages](https://aflyingkelp.github.io/hide-and-sleigh/)

A first-person Christmas prop hunt for 2–10 players. Create a room and send your friends the game link and six-character code.

Move with WASD and sprint with Shift. Press E to copy a prop, X to return to normal, F to toggle the flashlight, and M to view the map.

The Pages frontend lives in docs/ and uses the hosted room server. To play locally with Node 24 or newer, run npm run dev, then open http://127.0.0.1:8765 in two tabs.
